# compliance-mapping · examples

Two OSCAL Catalog JSON files you can pair up to demo this skill without
having to generate anything from a PDF first. Both are freely
redistributable.

## Contents

| File                                                                          | Source / license                                                                                                                                                            | Role in a mapping                                                                                              |
| :---------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------- |
| `EU-GDPR.catalog.json`                                                        | Generated by `compliance-catalog` from the public GDPR text (Regulation 2016/679). Redistributable — the source document is EU public law and our extractor adds no license restrictions. | Typically the **source** (from-catalog) — "what does GDPR require?"                                            |
| `NIST_SP-800-53_rev5_MODERATE-baseline-resolved-profile_catalog.json`         | The official NIST SP 800-53 rev5 MODERATE baseline, resolved-profile form, distributed by NIST. Public domain (U.S. Federal Government work, 17 USC §105).                     | Typically the **target** (to-catalog) — "which NIST controls satisfy each GDPR requirement?"                    |

## Suggested demo pair

`EU-GDPR.catalog.json` → `NIST_SP-800-53_rev5_MODERATE-baseline-resolved-profile_catalog.json`

- 99 GDPR articles as source controls
- 177 NIST rev5 MODERATE controls as target controls
- Well-known real-world mapping problem (GDPR ↔ NIST is a canonical
  compliance question), so the audience recognises the setup instantly.

## Use with the skill

Point `source_catalog` and `target_catalog` at the two files above; pick
any writable output dir. The skill's Phase 0-pre will auto-start the
live viewer at `http://127.0.0.1:8850/` so the operator watches the
mapping build itself.

## Provenance notes

- `EU-GDPR.catalog.json` is our own artefact, derived from EU public
  law using the sibling `compliance-catalog` skill. If you want to
  regenerate it from scratch, use `compliance-catalog/examples/EU-GDPR.pdf`.
- The NIST profile file is copied unmodified from
  <https://github.com/usnistgov/oscal-content/>. It is redistributable
  under the terms NIST publishes on that repo (Public Domain in the U.S.).
- Nothing under this directory is derived from IBM-internal frameworks.
  Do not add such files here.
